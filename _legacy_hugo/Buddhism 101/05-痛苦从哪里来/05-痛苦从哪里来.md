# 第 5 天：痛苦从哪里来——三台不停运转的焦虑发动机

上回说到，痛苦的根源是有原因的。今天把这三台「发动机」拆开来看看。

佛学给它们取了三个名字：贪、嗔、痴。

这三个字听起来像道德批评——好像在说人太贪婪、太爱生气、太笨。完全不是这个意思。它们是三个操作层面的描述。

## 贪：想抓住好的东西不放

「贪」不是贪钱的意思。范围大多了。

喝到一杯好咖啡，心里马上冒出一个念头：「明天还要喝这个。」听到一首好听的歌，忍不住单曲循环三十遍。遇到一个聊得来的人，恨不得天天见面。

这种「还想再来一次」的冲动，就是贪。

问题在哪里？问题在于——再来一次的时候，感觉不一样了。第二次的咖啡没有第一次香，第三次有点习惯，第五次已经喝不出任何特别。但手还是伸过去。

我们不是在享受咖啡，是在追逐第一次的感觉。

## 嗔：想推开坏的东西不走

早上被闹钟吵醒，第一个念头：烦。地铁太挤，烦。老板又发消息，烦。不是今天特别烦——是每一天都有东西让人烦。

嗔的意思就是这种排斥反应。不一定是发脾气，更常见的是低强度的烦躁、不耐烦、隐隐的不爽。

跟贪一样，嗔也是自动的。人对不舒服的东西，本能就是推开。但生活中大部分不舒服是推不开的——交通拥堵、别人的性格、自己的情绪，都不是按一下「删除」就能消失的。

于是就卡在那儿：一边在忍受，一边在抗拒。双倍消耗。

## 痴：对不好不坏的东西感到无聊，然后开始胡思乱想

这是最隐蔽的一台发动机。

排队的时候，没什么特别的感觉，就是无聊。然后大脑开始自动播放：下午的会议有什么坑，上周那句话是不是说得不对，三年以后还能不能在这座城市待下去。

这些念头没有一个跟此时此刻有关。但人就是停不下来。

佛学管这个叫「痴」——不是愚蠢，是一种根本性的误解：误以为「我」和「我的想法」是同一个东西。

## 三台发动机加在一起

贪 + 嗔 + 痴，一起运转的时候：

- 遇到好的 → 想抓住 → 抓住了怕失去 → 焦虑
- 遇到坏的 → 想推开 → 推不开 → 愤怒
- 遇到不好不坏的 → 无聊 → 开始胡思乱想 → 焦虑和愤怒的原材料都有了

这就解释了第一天的那个问题：为什么明明没什么大事，还是觉得不满足？

因为人在自动巡航。

## 但是——这三台发动机可以被关掉吗

好消息：佛陀说可以。

不是靠意志力硬扛，不是靠念经把它念走，是通过**看清楚它是怎么转的**，让它自己停下来。就像一个小孩在耍脾气，你越骂他越闹，你只是安静看着，他闹一会儿就停了。

下一讲，聊聊那个听起来很神秘的词：涅槃。

> **今日禅句**
>
> 「诸法无我。」——《法句经》
>
> 解读：「我」不是一个固定不变的东西。它是念头、感受、记忆的组合——而这些全在变化。所以没必要跟每个念头都较真。
